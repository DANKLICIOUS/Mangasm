# Mangasm domain language

## Community Reputation

Trust-oriented score (0–100) from verification, positive feedback, safety education, and helpful community care. **Not** a sexual or match-based level system.

## Profile Style

Cosmetic visual theme unlocked by Community Reputation. Users may switch among unlocked styles freely.

## Active Style

The style currently applied to profile chrome: preferred if unlocked, otherwise the highest unlocked default.

## Reputation Event

An allowlisted positive (or rare penalty) event that may adjust Community Reputation. Never includes match count or romantic message volume.
