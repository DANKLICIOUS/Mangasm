# In-app unlock copy (App Store / Play safe)

## Toast / modal title

`New style unlocked`

## Body template

`{displayName}`  
`{badgeName}`  
`{badgeMeaning}`  
`Cosmetic only — switch anytime in Profile styles.`

## Examples

| Style           | Body                                                                                         |
| --------------- | -------------------------------------------------------------------------------------------- |
| Calm Studio     | New Member · Just joined and completed basic profile setup.                                  |
| Aspirational    | Rising Member · Building positive reputation through consistent, respectful activity.        |
| Precision Tech  | Trusted Member · Verified identity and strong positive community feedback.                   |
| Digital Flow    | Community Leader · Actively helps keep the community safe and supportive.                    |
| Bold Expression | Elite Verified · Highest trust level — fully verified and consistently positive contributor. |

## Never use

- Level up / grind / XP / power ranking
- Sexual, romantic, or “hotness” language
- Pressure to engage more to unlock
